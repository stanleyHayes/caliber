## Pre-Flight Checklist

### Backend Production Setup

- [ ] **Database**: Create Neon Postgres project
  - [ ] Enable pgvector extension (automatic on Neon)
  - [ ] Get DIRECT endpoint (not pooler)
  - [ ] Add `?sslmode=require` to DSN
  - [ ] Fill: `CALIBER_DATABASE_URL=<neon-dsn>`

- [ ] **Redis**: Create managed Redis (Render/Upstash/Redis Cloud)
  - [ ] Enable TLS (rediss://)
  - [ ] Get connection string with password
  - [ ] Fill: `CALIBER_REDIS_URL=<redis-dsn>`

- [ ] **AI Keys**: Verify existing keys work
  - [ ] `ANTHROPIC_API_KEY` (already populated from dev .env)
  - [ ] `OPENAI_API_KEY` (already populated from dev .env)
  - [ ] Test: `curl -H "x-api-key: $ANTHROPIC_API_KEY" https://api.anthropic.com/v1/models`

- [ ] **Generate Secrets**: Production-only keys
  ```bash
  # JWT Secret
  JWT_SECRET=$(openssl rand -base64 48)
  echo "CALIBER_JWT_SECRET=$JWT_SECRET"

  # Field Encryption Key
  ENC_KEY=$(openssl rand -base64 32)
  echo "CALIBER_FIELD_ENCRYPTION_KEY=$ENC_KEY"
  ```
  - [ ] Fill: `CALIBER_JWT_SECRET=<generated>`
  - [ ] Fill: `CALIBER_FIELD_ENCRYPTION_KEY=<generated>`

- [ ] **CORS Origins**: Get frontend URL
  - [ ] Deploy frontend to Vercel (or get staging URL)
  - [ ] Fill: `CALIBER_CORS_ORIGINS=https://your-domain.vercel.app`

### Frontend Production Setup

- [ ] **Get Backend URL**: Deploy API first
  - [ ] Render/Railway provides public URL (e.g., `https://caliber-api-xxx.onrender.com`)
  - [ ] Fill: `VITE_API_URL=<backend-url>`

- [ ] **Frontend Domain**: Set Vercel project domain
  - [ ] Vercel dashboard → Project Settings → Domains
  - [ ] Example: `https://projectcaliber.vercel.app`
  - [ ] Fill: `VITE_SITE_URL=<frontend-url>`

- [ ] **Analytics (Optional)**
  - [ ] Create Plausible account (privacy-respecting)
  - [ ] Add custom domain
  - [ ] Fill: `VITE_PLAUSIBLE_DOMAIN=projectcaliber.app`

- [ ] **Search Console (Optional)**
  - [ ] Google Search Console → Add property
  - [ ] HTML file verification token
  - [ ] Fill: `VITE_SEARCH_CONSOLE_HTML_FILE_TOKEN=<token>`

## Deployment Steps

### 1. Backend: Render (or Railway)

```bash
# 1. Create Render services via Blueprint or Dashboard
# 2. Set secrets in Render dashboard → Environment
render env create caliber-api \
  --secret CALIBER_DATABASE_URL="<neon-dsn>" \
  --secret CALIBER_REDIS_URL="<redis-dsn>" \
  --secret ANTHROPIC_API_KEY="<key>" \
  --secret OPENAI_API_KEY="<key>" \
  --secret CALIBER_JWT_SECRET="<generated>" \
  --secret CALIBER_FIELD_ENCRYPTION_KEY="<generated>" \
  --secret CALIBER_CORS_ORIGINS="https://your-domain.vercel.app"

# 3. Verify deployment
curl https://caliber-api-xxx.onrender.com/healthz
# Expected: {"status":"ready"}

# 4. Run migrations (one-off job)
render jobs create caliber-migrate \
  --docker-file deploy/Dockerfile.migrate
```

### 2. Frontend: Vercel

```bash
# 1. Connect GitHub repo to Vercel (or use CLI)
vercel link

# 2. Set environment variables
vercel env add VITE_API_URL
# Prompt: Enter value → https://caliber-api-xxx.onrender.com

vercel env add VITE_SITE_URL
# Prompt: Enter value → https://projectcaliber.vercel.app

# 3. Deploy
vercel --prod

# 4. Verify build
curl https://projectcaliber.vercel.app
# Expected: 200 OK, prerendered HTML
```

### 3. Connectivity Test

```bash
# Backend health
curl https://caliber-api-xxx.onrender.com/readyz

# Frontend loads
curl https://projectcaliber.vercel.app | grep -o "<title>.*</title>"

# CORS preflight (from frontend browser console)
fetch('https://caliber-api-xxx.onrender.com/v1/auth/status', {
  credentials: 'include'
})
.then(r => r.json())
.then(d => console.log('CORS OK', d))
.catch(e => console.error('CORS FAIL', e))
```

## Production Safety Checks

### Before Going Live

```bash
# 1. Verify required vars are set
set -a; . .env.production; set +a
for var in CALIBER_DATABASE_URL CALIBER_REDIS_URL \
           CALIBER_JWT_SECRET CALIBER_FIELD_ENCRYPTION_KEY \
           CALIBER_CORS_ORIGINS ANTHROPIC_API_KEY OPENAI_API_KEY; do
  if [ -z "${!var}" ]; then
    echo "❌ Missing: $var"
  else
    echo "✅ Set: $var (length ${#!var})"
  fi
done

# 2. Verify database reachable
psql "$CALIBER_DATABASE_URL" -c "SELECT version();"
# Expected: PostgreSQL X.X.X output

# 3. Verify Redis reachable
redis-cli -u "$CALIBER_REDIS_URL" ping
# Expected: PONG

# 4. Verify API health
curl -s https://caliber-api-xxx.onrender.com/healthz | jq .

# 5. Verify frontend connects to API
# Open browser DevTools → Network → test API call
```

## Troubleshooting

### "Connection refused" on API startup
```bash
# 1. Verify database connection
psql "$CALIBER_DATABASE_URL"

# 2. Verify Redis connection
redis-cli -u "$CALIBER_REDIS_URL" ping

# 3. Check logs
CALIBER_LOG_LEVEL=debug go run ./cmd/api 2>&1 | head -50
```

### "Field encryption key missing" error in prod
```bash
# Production MUST have the encryption key
# Without it, PII is silently stored in plaintext (data loss risk)
# Solution: Generate and set CALIBER_FIELD_ENCRYPTION_KEY
openssl rand -base64 32
```

### Frontend can't reach API (CORS error)
```bash
# 1. Check CALIBER_CORS_ORIGINS on backend
echo $CALIBER_CORS_ORIGINS

# 2. Verify it matches frontend domain exactly
# Example: https://projectcaliber.vercel.app (no trailing slash)

# 3. Browser DevTools → Network → OPTIONS request
# Should return: Access-Control-Allow-Origin: https://projectcaliber.vercel.app
```

### "Port already in use" (local dev)
```bash
# HTTP port conflict
lsof -i :8080
kill <PID>

# gRPC port conflict
lsof -i :9090
kill <PID>
```

## Key Rotation (Advanced)

See `docs/runbooks/key-rotation.md` for:
- Rotating JWT secrets (new access/refresh tokens)
- Rotating field-encryption keys (customer PII)
- Rotating API keys (Claude, OpenAI)

Example: Field encryption key rotation
```bash
# 1. Generate new key
NEW_KEY=$(openssl rand -base64 32)

# 2. Update environment
CALIBER_FIELD_ENCRYPTION_KEY="$NEW_KEY"
CALIBER_FIELD_ENCRYPTION_KEY_PREVIOUS="$OLD_KEY"

# 3. Reencrypt all rows in database
go run ./cmd/reencrypt

# 4. Verify all rows are reencrypted (check database)
# 5. Clear PREVIOUS key
unset CALIBER_FIELD_ENCRYPTION_KEY_PREVIOUS
```
